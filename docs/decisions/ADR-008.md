# ADR-008: Price API Choices per Asset Class

## Status
Accepted

## Date
2026-04-24

## Context
The portfolio service needs a live price (in INR) for every held asset to compute current
value, allocation percentages, and eventually XIRR. Assets span five distinct instrument
types — US equities, Indian equities/ETFs, Indian mutual funds, crypto, and physical gold
— each with a different pricing source and identifier standard.

The `price_source` column on the `asset` table routes each asset to the correct API.
The enum value names the **data standard / identifier type**, not the specific HTTP
endpoint. This decouples the schema from vendor lock-in: if a vendor is replaced, only
the service code changes, not the database.

## Decision

### Price source routing

| `price_source` | `ticker_symbol` convention | HTTP endpoint | Price currency | INR conversion |
|---|---|---|---|---|
| `yahoo_finance` | US ticker (e.g. `MSFT`, `CRM`) | Finnhub `/api/v1/quote` | USD | × USD/INR rate |
| `yahoo_finance` | NSE ticker with `.NS` suffix (e.g. `HDFCBANK.NS`) | Finnhub `/api/v1/quote` | INR | none |
| `amfi` | AMFI scheme code (e.g. `122639`) | `https://api.mfapi.in/mf/{code}/latest` | INR | none |
| `coinmarketcap` | CoinGecko `ids` param (e.g. `bitcoin`, `ethereum`, `solana`) | CoinGecko `/api/v3/simple/price?ids={id}&vs_currencies=inr` | INR | none |
| `metals_api` | Metal code `XAU` | Metals-API `/api/latest?symbols=XAU&base=USD` | USD | × USD/INR rate |
| `manual` | Any | No API call | — | — |

### API details

**Finnhub** (`yahoo_finance`)
- Used for: US equities (NASDAQ/NYSE), Indian equities and ETFs (NSE), Sovereign Gold Bonds
- Free tier: 60 req/min, no daily limit
- NSE convention: Indian tickers must use `.NS` suffix. NSE-specific suffixes (`-X`, `-T`, `-XT`) are stripped before appending `.NS`
- USD detection: if `ticker_symbol` does NOT end in `.NS` or `.BO`, price is in USD → multiply by USD/INR rate
- API key: `FINNHUB_API_KEY`

**mfapi.in** (`amfi`)
- Used for: all Indian mutual funds (including gold mutual funds like SBI Gold, Kotak Gold Fund)
- `ticker_symbol` holds the AMFI scheme code (numeric string)
- Response field: `data[0].nav`
- Free tier: unlimited, no API key required
- Updates: ~6 times daily after market close

**CoinGecko** (`coinmarketcap`)
- Used for: Bitcoin, Ethereum, Solana
- `ticker_symbol` holds the CoinGecko `ids` parameter value (`bitcoin`, `ethereum`, `solana`) — NOT the exchange symbol (BTC/ETH/SOL)
- Prices returned directly in INR via `vs_currencies=inr`
- Free tier: ~30 req/min, no API key required

**Metals-API** (`metals_api`)
- Used for: physical gold only (`ticker_symbol = 'XAU'`)
- Returns XAU/USD rate; convert to INR price per gram: `(1 / rates.XAU) * usdToInr / 31.1035` (troy oz to grams)
- Free tier: varies; API key required
- API key: `METALS_API_KEY`

**Frankfurter** (USD/INR rate — shared by `yahoo_finance` USD assets and `metals_api`)
- `https://api.frankfurter.app/latest?from=USD&to=INR`
- Free, no API key, ECB rates updated daily
- Cached in-memory with TTL 1 hour

**Manual** (`manual`)
- EPF, Gratuity, Leave Encashment, Bank Savings, Physical Diamond
- No API call. Latest value is stored directly in the `holding` table and updated manually
- These assets do not participate in automated price refresh

## Alternatives Considered

### Use Yahoo Finance directly instead of Finnhub
Yahoo Finance has no official public API. The `yfinance` Python library works but is
Python-only and subject to breaking changes. Finnhub provides the same data via a stable
REST API with a free tier. Rejected: no official API, wrong language.

### Use CoinMarketCap instead of CoinGecko for crypto
CoinMarketCap free tier requires an API key and has a 10k monthly credit limit.
CoinGecko free tier requires no key and supports direct INR pricing. Rejected: CoinGecko
is simpler and more generous. Note: `price_source = 'coinmarketcap'` retains the original
enum name; the actual call goes to CoinGecko.

### Use a gold ETF price as proxy for physical gold
Considered using `GOLDBEES.NS` or `AXISGOLD.NS` via Finnhub as a proxy for physical gold.
Rejected: ETF prices include fund expense ratios and can trade at premium/discount to NAV.
Metals-API provides the direct spot price.

## Consequences
- `FINNHUB_API_KEY` and `METALS_API_KEY` must be set in `.env`
- mfapi.in and CoinGecko require no API keys
- The `asset-price` service must detect USD vs INR for `yahoo_finance` assets by checking
  whether `ticker_symbol` ends in `.NS` or `.BO`
- CoinGecko `ids` values (full names like `bitcoin`) must be stored in `ticker_symbol`,
  not exchange symbols (BTC/ETH/SOL)
- `manual` assets are excluded from portfolio total if their `holding.current_value` is NULL
