# ADR-013: Replace Metals-API with GoldAPI for Physical Gold Pricing

## Status
Accepted — Supersedes ADR-008 (physical gold section only)

## Date
2026-04-25

## Context
ADR-008 specified Metals-API as the price source for physical gold (`price_source = 'metals_api'`).
Metals-API is a paid service. GoldAPI (goldapi.io) provides the same physical gold spot price in
INR directly, requires no USD conversion step, and the user already has an API key.

## Decision
Replace Metals-API with GoldAPI for the `gold_api` price source:

| `price_source` | API | Endpoint | Response field | Key |
|---|---|---|---|---|
| `gold_api` | GoldAPI (goldapi.io) | `GET https://www.goldapi.io/api/{symbol}/INR` | `price_gram_24k` | `GOLD_API_KEY` |

- `ticker_symbol` for physical gold: `XAU`
- `price_gram_24k` is already in INR — no USD/INR conversion needed
- Request header: `x-access-token: {GOLD_API_KEY}`

### Migration
The `metals_api` enum value is removed from `price_source` and replaced with `gold_api`.
Migration `004_replace_metals_api_with_gold_api.sql` handles this via drop-and-recreate of the
enum type (rather than `ALTER TYPE ADD VALUE`) to avoid PostgreSQL's "unsafe new enum value"
error that occurs when `ADD VALUE` and its first use share a database session.

### Env var
`GOLD_API_KEY` must be set in `.env` and forwarded to the backend Docker container in
`docker-compose.yml` (under `backend.environment`).

## Consequences
- `METALS_API_KEY` is no longer used; can be removed from `.env`
- `GOLD_API_KEY` must be present in `.env` and in `docker-compose.yml` backend environment block
- Physical gold pricing is now direct INR with no currency conversion step — simpler and more accurate
- ADR-008 "Metals-API" section is superseded; all other price sources in ADR-008 remain unchanged
